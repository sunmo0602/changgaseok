1. Who uses this app

창가석 is a private tool used only by its owner. It is not offered to the public and does not collect data from other people.

2. Data accessed

With the owner's Google authorization, the app uses the YouTube Data API to upload videos and thumbnails to the owner's channel, to set their metadata and publish time, and to read the owner's own channel and video information.

3. Storage

The OAuth tokens and upload records are stored only on the owner's own computer. They are not sent to any server operated by this app, and there is no such server.

4. Sharing

No data is sold, shared or transferred to third parties. Data is sent only to Google/YouTube as required to perform the uploads.

5. Retention and deletion

The owner can delete the local tokens and records at any time, and can revoke the app's access at Google Account permissions.

6. YouTube API Services

This app uses YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

7. Contact

Use the support email address shown on the Google sign-in consent screen of this app.
